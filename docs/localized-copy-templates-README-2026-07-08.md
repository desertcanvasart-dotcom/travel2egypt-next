# ES/JA owner-fill copy templates — climate signature + price manifest

Both locale-gated batches (weather-page climate hero, price-manifest table) are
**EN-only at launch** and blocked solely on owner-authored ES/JA copy — the code
is locale-ready, and the strings are owner-locked (never agent-drafted). These
templates enumerate exactly what to translate. Generated by
`scripts/gen-localized-copy-templates.ts` (read-only, re-runnable).

## Files
- `docs/climate-signature-copy-ES-JA-template-2026-07-08.csv` — **41 cities × up
  to 5 fields = 205 strings** (`descriptors`, `gapText`, `troughText`, `caption`,
  `seasonLabel`). Columns: `citySlug, field, en, es, ja`. Fill `es` + `ja`.
- `docs/price-manifest-chrome-ES-JA-template-2026-07-08.csv` — **8 strings**: the
  `Checked` stamp label + date, the 4 table headers (`Site/Adult/Student/Hours`),
  and the 2 owner-locked footnote paragraphs. Columns: `key, en, es, ja, note`.

## How to fill
Translate each `en` cell into the `es` and `ja` columns. Leave `en` unchanged.

**Climate — keep the numbers.** `gapText`, `troughText`, and `caption` assert °C
figures that are drawn from the chart data (e.g. Cairo `gapText` "14°" == the
day–night gap the SVG renders; `troughText` "9°" == the January low). Translate
the words, **preserve every number and the `°` symbol** — the numeric-claim gate
checks es/ja against the same data at ±1°, same as EN. `seasonLabel` is the
all-caps banner (e.g. "THE SEASON — OCTOBER TO APRIL"); keep the caps convention
your locale uses. Style refs: the EN voice is terse and evocative (see the mock's
Qena/Aswan/Alexandria records).

**Price — `EGP` and the em-dash stay.** `stamp_date` localizes ("julio de 2026",
"2026年7月"). The 2 footnotes are the substantive locked copy — translate faithfully.

## Wire-in path (after the owner fills the CSVs)
1. A follow-up script reads each filled CSV and writes the `es`/`ja` values into:
   - climate → the `editorial.es` / `editorial.ja` slots in `src/data/climate/index.ts`
   - price → a new locale-keyed chrome map consumed by `PriceManifest.tsx` (a small
     plumbing refactor lands with the wire-in, mirroring climate).
2. Re-run the numeric-claim gate (climate) to confirm es/ja figures match the data.
3. **Flip the locale gate** so the localized hero/table renders:
   - climate: `src/app/(site)/[locale]/guide/[citySlug]/[slug]/page.tsx` gate
     `kind=='climate' && locale=='en'` → include the locales with filled data
     (per-locale, graceful: a city missing es copy keeps its current es hero).
   - price: `localeGate` / the `priceData` locale rule.
4. Browser-verify a couple of cities/pages per locale; build green.

## Out of scope for these templates (flag if wanted)
- Price **per-row notes** and **governorate kickers** are owner data in
  `src/data/prices/index.ts`, city-specific — not in this chrome template. If they
  should localize too, that's a separate per-row pass.
- Climate **data spot-check** (the DRAFT numeric arrays) is independent — see
  `src/data/climate/index.ts` header + the master to-do.

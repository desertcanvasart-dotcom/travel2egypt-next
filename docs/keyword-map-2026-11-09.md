# Keyword map: one page per commercial search (9 Nov 2026)

Phase B4 of `docs/product-ranking-plan-2026-11-09.md`.

## Source

Ahrefs Keywords Explorer and GSC Insights are locked on the free Ahrefs plan, so this map uses **Google Search Console**: the `https://travel2egypt.org/` property, read-only, for searches containing tour, cruise, package, holiday, trip, viaje, crucero, paquete and similar words.

- **Impressions** are how often the site appeared for a search. They are *not* total search volume, because a page on position 60 is rarely seen. Treat them as a floor and as a way to rank clusters against each other.
- **Last 3 months** (Aug–Nov 2026): 42.4K impressions, **77 clicks**, average position **40**.
- **Last 16 months**: 622K impressions and 1.43K clicks, average position 42. Most of that came before the January 2026 drop, when the old site ranked.
- Positions below are 3-month averages. "→ old URL" means Google still shows a WordPress-era address that now redirects.

## Overall picture

- People search these terms all the time. The site shows up, but on **pages 3–7**, so it gets almost no clicks.
- **Close to page 1 (positions 8–20):** Dendera & Abydos, Nile cruise + Hurghada stay, Mount Sinai, Luxor day tours, Siwa, Essential Egypt, ship names, Romantic Egypt, Sharm packages. These are the B5 priorities.
- **Big but far (positions 40–70):** "nile cruise", "egypt holidays", "egypt tour packages" and "small group egypt tours". These need B5 alignment *and* Phase D links.
- **Dead pages:** 25 pages Google ranked for commercial searches returned 404 (e.g. `/7-days-egypt-tours`, `/es/tours-a-egipto-desde-espana`). They are redirected in the same PR as this document.
